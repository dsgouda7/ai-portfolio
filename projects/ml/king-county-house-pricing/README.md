# King County House Price Modeling

Portfolio notebook that walks through a practical regression workflow on King County housing data.

## What this project covers

- Data ingestion and schema checks
- Missing-value handling and basic wrangling
- Exploratory analysis for feature signal
- Linear regression baselines
- Ridge + polynomial refinement on a holdout split

## Files

- `house-price-modeling.ipynb`: main notebook

## Notes

This version is written as an engineering progression, not a guided lab. It keeps the same analytical flow but removes assignment-style prompts and handholding text.

## Run

Open the notebook and run top to bottom in Jupyter.

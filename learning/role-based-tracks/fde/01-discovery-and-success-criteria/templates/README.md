# Discovery Template Pack

These templates mirror the `DSC-01` through `DSC-05` Stage 1 artifact contract. Use stable IDs, retain source references, and preserve the original evidence class when moving a statement between artifacts.

| Template | Artifact use |
|---|---|
| [stakeholder-and-user-map.md](stakeholder-and-user-map.md) | `DSC-01`: affected users, authority, access, and interview coverage |
| [workflow-and-baseline.md](workflow-and-baseline.md) | `DSC-02` and `DSC-03`: current state, failures, measurements, and limitations |
| [outcomes-and-acceptance.md](outcomes-and-acceptance.md) | `DSC-04`: outcomes, non-goals, sliced acceptance criteria, and golden workflows |
| [decision-action-inventory.md](decision-action-inventory.md) | Proposal, approval, commit, audit, compensation, and prohibited-action boundaries |
| [data-and-integration-inventory.md](data-and-integration-inventory.md) | Sources, owners, purpose, access, lifecycle, and integration unknowns |
| [discovery-register-and-backlog.md](discovery-register-and-backlog.md) | `DSC-05`: assumptions, conflicts, risks, unknowns, and prioritized evidence work |
| [discovery-review.md](discovery-review.md) | Gate review, conditions, decisions, and handoff to architecture translation |
| [notebook-output-record.md](notebook-output-record.md) | `NOT RUN`-by-default record for later observations, limitations, and evidence references |

Blank fields are intentionally explicit. `Unknown` is a valid value; an invented answer is not.

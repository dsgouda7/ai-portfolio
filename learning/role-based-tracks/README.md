# Role-Based Learning Tracks

These tracks organize existing technical chapters around the work performed in a particular role. They are designed to run alongside the subject tracks under `learning/`, not replace them or form a separate prerequisite ladder.

Use a role track when you want to practice joining concepts across model behavior, data, evaluation, infrastructure, delivery, and operations in one job-shaped workflow.

| Track | Focus | How to use it |
|---|---|---|
| [AI Engineer](ai-engineer/README.md) | Connect data, model adaptation, retrieval, evaluation, serving, releases, and feedback into one production loop. | Pair its operational chapters with the relevant GenAI, agentic AI, and infrastructure chapters as you learn them. |
| [Forward Deployed Engineer](fde/README.md) | Turn an ambiguous customer workflow into a bounded design, rollout, operating model, and handoff. | Pair it with the technical chapters needed by the current customer decision; use its Riverside exercises to practice judgment and communication. |

The notebooks use local or synthetic fixtures unless a chapter explicitly says otherwise. Completing a track demonstrates structured practice, not independent production authority or live-cloud validation.

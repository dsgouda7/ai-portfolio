# Contents: Retrieval-Augmented Generation

Give each answer permitted source evidence and locate the owner of a failure.

## Required route

- [Hybrid Retrieval Theory: When One Search Signal Lies](01a-hybrid-retrieval-theory.ipynb) — Expose where matching words and matching meaning each miss useful passages, then combine their search results.
- [Hybrid Retrieval - Handwritten Theory Notes](01-hybrid-retrieval-theory.md) — Review how to combine different search signals without confusing relevance with permission to read a passage.
- [Hybrid Retrieval Lab: Build the Authorized Pipeline in PyTorch](01b-hybrid-retrieval-lab.ipynb) — Build a two-signal search pipeline, combine result ranks, and enforce which evidence the caller may see.
- [RAG Failure Localization and Evaluation](02-rag-failure-localization-and-evaluation.ipynb) — Use known-good passages to distinguish a search failure from an answer-writing failure and retain one evidence record per question.
- [RAG Evaluation: A Diagnostic Theory Note](02-rag-failure-localization-and-evaluation-theory.md) — Review how controlled source substitutions identify the layer responsible for a bad answer.

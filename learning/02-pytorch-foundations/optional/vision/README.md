# Optional Vision

Optional image labs reuse the module and update loop to show spatial filters and compression.
They generate small images locally; neither is required for the language route.

1. [CNNs](01-pytorch-cnns.ipynb) · [Handwritten theory](01-pytorch-cnns-theory.md) — inspect filters, feature maps, pooling, and gradient routes.
2. [Autoencoders](02-pytorch-autoencoders.ipynb) · [Handwritten theory](02-pytorch-autoencoders-theory.md) — reconstruct pixels from a compact code. This is not a VAE.

# Optional Embedding History

**Contents:** [directory map](CONTENTS.md)

After [tokenization and embeddings](../../02-tokenization-and-embeddings/README.md), open
[From Counts to Static Geometry](01-from-counts-to-static-geometry.ipynb).
Compare one-hot and bag-of-words with Word2Vec and GloVe, then ask why `bank` still gets
one stored row in two different contexts.

From this directory, run [`setup.ps1`](setup.ps1) on Windows or [`setup.sh`](setup.sh) on
Linux/macOS. It creates or reuses `.venv`, installs [requirements](requirements.txt), and
assigns kernel `stage03-language-model-optional-embedding-history`.
Use `-SkipKernel` or `--skip-kernel` if you only need the environment.

This is optional background, not a search or sentiment lab. No separate theory companion
is needed for the main route.

# Recurrent Neural Networks

[The PyTorch RNN Bridge](01-pytorch-rnn-bridge.ipynb) builds recurrent sequence modeling, LSTM state, next-token training, and autoregressive generation before the Transformer chapters.

Run `setup.ps1` on Windows or `setup.sh` on Linux/macOS. Either script creates or reuses this chapter's `.venv`, installs the adjacent `requirements.txt`, registers the chapter-unique `genai-01-rnns` Jupyter kernel, and assigns it to the notebook.

# PyTorch Fundamentals

[The Antarctic Field Guide](01-keras-to-pytorch-antarctic-field-guide.ipynb) translates familiar Keras workflows into explicit PyTorch tensors, modules, autograd, training, and inference.

Run `setup.ps1` on Windows or `setup.sh` on Linux/macOS. Either script creates or reuses this chapter's `.venv`, installs the adjacent `requirements.txt`, registers the chapter-unique `genai-00-pytorch-fundamentals` Jupyter kernel, and assigns it to the notebook.

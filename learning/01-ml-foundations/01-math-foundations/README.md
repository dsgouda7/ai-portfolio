# Mathematical Foundations for ML

**Start:** [Mathematical Foundations for Machine Learning](math-foundations-for-ml.ipynb).
A free kick makes vectors, change, accumulation, matrix updates, and uncertainty visible.
Theory and experiments are together in the notebook; no separate theory file is needed.

Follow the launch arrow, freeze the velocity, add 28 exact constant-gravity moves, then
compare one precise aim with a cloud of imperfect attempts. The matrix example explicitly
switches from physical state to illustrative features; neither set of weights is learned.

**Prerequisite:** basic arithmetic. **Contents:** [lesson map](CONTENTS.md).

## Setup

- Windows: `.\setup.ps1`
- Linux or macOS: `bash ./setup.sh`

Use the `stage01-math-foundations` kernel. The checked-in source is currently output-free.
Keep future source updates output-free too; run results belong in a separate copy.
The static assets in `images/` keep the visual evidence readable before execution.
